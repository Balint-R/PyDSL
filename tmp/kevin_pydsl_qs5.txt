3. Linalg binop semantics
https://github.com/Huawei-CPLLab/PyDSL/issues/26
Should memref and tensor have the same semantics? Should we modify tensors in-place?
- For MLIR people, it makes more sense to treat memref and tensor differently

a[f(1)] += 1
a[f(1)] = a[f(1)] + 1

Semantics of a += b is clear (modify in-place for both MemRef and Tensor).
Semantics of a + b is clear (only supported for Tensor).
The question is what to do for linalg.add(a, b, out=c)?
- Modify c
- In general: memref is like a C pointer, tensor is like a Python list


a: Tensor
a[1, 2] = 3
new_a = tensor.insert(a, (1, 2), 3)




# Current behaviour

b = a
b[1, 2] = 3
# a gets modified

b = a[:]
b[1, 2] = 3
print(a)
# a does not get modified
